# frogger-plus

This repository holds no code. It contains a portfolio research memo:

- `portfolio/Buy-and-Hold-vs-InTheMoney-Sept-2026.pdf`: a $500 buy-and-hold portfolio (about 39% AI compute, 36% GLP-1 pipeline, 15% power and grid, 10% index and T-bills) with per-position bands designed to be held with quarterly band checks and compared against InTheMoney's actively managed Autopilot portfolio.
- `portfolio/portfolio.md`: the markdown source of the memo (allocation, theses, rebalancing bands, kill switches).
- `portfolio/research-notes.md`: dated sources and URLs for every figure, plus the items that could not be verified.
- `portfolio/Rebalance-Zero-to-Hero-2026-09-17.xlsx` and `portfolio/Orders-2026-09-18.csv`: the buys-only order list to bring a live 12-position account onto the plan, the per-position band table, and a formula-driven quarterly check sheet.

Prepared September 16, 2026, revised September 17. Educational research, not individualized investment advice.
