# frogger-plus

This repository holds no code. It contains a portfolio research memo:

- `portfolio/Buy-and-Hold-vs-InTheMoney-Sept-2026.pdf`: a $500 buy-and-hold portfolio (45% AI compute, 40% GLP-1 pipeline, 15% ballast) designed to be held with quarterly band checks and compared against InTheMoney's actively managed Autopilot portfolio.
- `portfolio/portfolio.md`: the markdown source of the memo (allocation, theses, rebalancing bands, kill switches).
- `portfolio/research-notes.md`: dated sources and URLs for every figure, plus the items that could not be verified.

Prepared September 16, 2026. Educational research, not individualized investment advice.
